# AI_GOVERNANCE/
## نظام حوكمة الذكاء الاصطناعي على مشروع M130

هذا المجلد يحوي **عقد العمل الإلزامي** لأي ذكاء اصطناعي يعمل على المشروع.

## الملفات

| الملف | الدور | يُحدَّث؟ |
|---|---|---|
| `AI_OPERATING_RULES.md` | العقد الكامل (14 قسم) | عند تغيير القواعد فقط |
| `LESSONS_LEARNED.md` | bugs سابقة + حلولها | بعد كل bug يُحلّ |
| `BASELINES.md` | runs معتمدة (snapshots) | بعد كل run ناجح |
| `AI_SESSION_TEMPLATE.md` | نموذج بداية جلسة | لا — يُنسخ فقط |
| `AI_BOOT_PROMPT.txt` | prompt يدوي لـAIs خارجية | عند تغيير القواعد |
| `README.md` | هذا الفهرس | عند إضافة ملف للمجلد |

## التحميل التلقائي

ملف `.windsurf/rules/00_mandatory_boot.md` (في جذر المشروع، خارج هذا المجلد)
يُحمَّل **تلقائياً** في كل جلسة Cascade ويُجبر الذكاء على قراءة هذه الملفات.

## للذكاءات الخارجية (ChatGPT/Claude Desktop/...)

استخدم `AI_BOOT_PROMPT.txt` يدوياً — انسخه والصقه في بداية كل محادثة.

## للمالك

- لا تُعدّل ملف داخل هذا المجلد بدون توثيق التغيير في git.
- زِد رقم النسخة في رأس `AI_OPERATING_RULES.md` عند أي تعديل جوهري.
- عند إضافة قاعدة جديدة: حدّث الملف نفسه + `.windsurf/rules/00_mandatory_boot.md` + الـmemory الدائمة.
