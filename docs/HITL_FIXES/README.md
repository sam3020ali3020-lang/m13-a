## كَيف تُضيف توثيقاً جَديداً

1. أَنشِئ ملفاً بِاسم `YYYY-MM-DD_FIX_<descriptive_name>.md`
2. اِتَّبِع نَفس البِنية:
   - الأَعراض (قَبل/بَعد)
   - التَّشخيص (دَورات التَّحقيق)
   - الإصلاح النِّهائي (ملف:سَطر)
   - الدُّروس المُستَفادة
   - كيف نُتَأَكَّد مِن استِمرار الإصلاح
3. حَدِّث هذا الـREADME
